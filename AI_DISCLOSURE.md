# AI Use and Code Provenance

## Tools

- **ChatGPT / Codex CLI (OpenAI)** and **Claude Code (Anthropic)**: coding assistants and general assistants.

## What the tools were used for

| Activity | AI role | Author role |
|---|---|---|
| Research question, model choices, baselines, evaluation protocol | Discussion and literature search support | Decided the research question, the models, the baselines and the evaluation rules |
| Experiment code (`src/sarcasm`, original per-experiment code) | Wrote and debugged code from the author's specifications | Specified each experiment, reviewed the code, ran and monitored the experiments |
| This repository | Claude Code consolidated the per-experiment research code into this package: moved files, replaced hard-coded paths with config placeholders, removed protocol bookkeeping, wrote the scripts, configs, README and result-collection code | Reviewed the repository and the equivalence checks |
| Result analysis | Computed summaries and statistics with the scripts in `src/sarcasm/analysis` and `src/sarcasm/cv` | Interpreted the results and checked them against the saved records |
| Writing (reports, paper, this README) | Drafting, editing and translation | Final text, all claims and all references checked by the author |

## Code provenance by component

| Component | Files | Origin |
|---|---|---|
| Model definitions | `src/sarcasm/models/*` | Written for this project with AI assistance; LoRA is an own implementation of Hu et al. (2022); pretrained encoders loaded through Hugging Face Transformers |
| Training loops | `src/sarcasm/train/*`, `src/sarcasm/cv/cv_*.py` | Written for this project with AI assistance; computation unchanged from the runs reported in the paper |
| Data preparation | `src/sarcasm/data/*` | Written for this project with AI assistance; OCR through the PaddleOCR library |
| Statistics and analysis | `src/sarcasm/analysis/*`, `src/sarcasm/cv/analyze_*.py` | Written for this project with AI assistance |
| Scripts, configs, README | `scripts/*`, `configs/*`, `*.md` | Generated by Claude Code during consolidation from the original experiment records; reviewed by the author |
| Third-party code | — | None copied or modified. Libraries are listed in `requirements.txt` and `requirements-ocr.txt` |

## How outputs were checked

- Every number in `results/` was collected from the saved run records (each row of `results/official_split_runs.csv`
  names its source record).
- The analyses in this repository were re-run on the shipped predictions and reproduce the original
  `test_bootstrap` and 5-fold CV results field by field.
- Model initialization is pinned by SHA-256 per run; the consolidated code rebuilds the recorded initial weights.
- All references were opened and checked by the author.

## Student-conducted work

Formulation of the research question, choice of models and baselines, design of the
evaluation (strong CLIP baseline, multi-seed reporting, 5-fold CV), running and monitoring all experiments,
interpretation of the results, and the conclusions of the paper.
