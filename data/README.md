# Data

Nothing in this directory except `cv5/folds.json` is committed. Everything else is downloaded or generated by the
scripts below.

## Dataset

**MMSD2.0** (Qin et al., Findings of ACL 2023): image–text tweets labelled sarcastic / non-sarcastic, with the
spurious cues of the original MMSD removed and labels re-annotated.

| Item | Value |
|---|---|
| Source | Hugging Face `coderchen01/MMSD2.0`, sub-directory `mmsd-v2` |
| Revision | `5b39e5b844accf2331d1738a3d91d4cb59005a50` |
| Splits | train 19,816 / validation 2,410 / test 2,409 (official split) |
| Fields | `image`, `text`, `label` (1 = sarcastic), `id` |

`python scripts/download_assets.py` downloads this revision with the `datasets` library and writes the directory of
the arrow files to `data/arrow_root.txt`. The dataset is not redistributed here; use it under the terms of its
original release.

## Generated files

`bash scripts/prepare_data.sh` produces:

```
data/
├── arrow_root.txt                 path of the MMSD2.0 arrow files (download_assets.py)
├── hf_datasets/                   Hugging Face dataset cache (download_assets.py)
├── evidence/
│   ├── train|validation|test/
│   │   ├── ocr.jsonl              PaddleOCR lines per image: {"id", "index", "image_sha256",
│   │   │                          "lines": [{"text", "score", "box_normalized"}]}
│   │   ├── ocr_summary.json       row count, images with text, sha256 of ocr.jsonl
│   │   └── ocr_config.json
│   └── clip/                      frozen CLIP ViT-B/32 image/text vectors (input of the standalone OCR branch)
├── bias_pools/
│   ├── train_labels.json
│   └── train_bias_pools.json      bias-line pools of the text-swap variant (official split)
├── cv5/
│   ├── folds.json                 5-fold image-grouped split of train+validation (committed)
│   ├── pool_labels.json
│   └── fold{0..4}/bias_pools.json bias-line pools from each fold's inner-train rows
└── dinov2-small/                  optional: DINOv2 patch tokens (interaction-gated model only)
```

| Step | Command | Time (RTX 2070 SUPER) |
|---|---|---|
| OCR (PaddleOCR 3.3.3, PP-OCRv5 server detection + English mobile recognition, separate environment) | `src/sarcasm/data/ocr_paddle.py` | train 50 min, validation 6 min, test 6 min |
| Frozen CLIP vectors | `python -m sarcasm.data.cache_clip` | ~10 min |
| Bias-line pools | `python -m sarcasm.data.bias_lines`, `python -m sarcasm.cv.prep_pools` | ~2 min (CPU) |
| DINOv2 cache (optional) | `python -m sarcasm.data.cache_dino` | ~15 min |

Original OCR output: 15,500 / 1,887 / 1,863 images with text in train / validation / test; sha256 of `ocr.jsonl`
`cfd5b5a5…`, `eea458b3…`, `d31f5389…`. `python scripts/check_data.py` compares your files with these values.
The number of OCR words per image of this original output is shipped in `results/ocr_word_counts.csv.gz`, so the
statistical analyses can be recomputed from the shipped predictions without running OCR.
PaddleOCR results can differ slightly across GPUs and drivers; see `scripts/check_data.py` for what this affects.

## Cross-validation folds

`cv5/folds.json` (sha256 `710e0905…`) was produced by `python -m sarcasm.cv.make_folds` (seed 20261108). It pools
train + validation (22,226 rows, 21,916 distinct images), assigns whole image groups to 5 label-stratified folds,
and inside the 4 training folds of each outer fold holds out ~10% of image groups as the inner validation set
(checkpoint selection only). The test split is never used.
